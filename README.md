# Pro-Muslim Mushaf pages (Hafs)

Static assets for the Pro-Muslim app: 604 pages of Mushaf al-Madinah (Hafs from Asim) as SVG,
plus per-page ayah polygon JSON and `surah.json`.

```
svg/001.svg … 604.svg     page artwork
json/001.json … 604.json  ayah polygons per page
json/surah.json           surah index
```

Served through jsDelivr: `https://cdn.jsdelivr.net/gh/Younes12345698/pro-muslim-mushaf@v1/svg/001.svg`
